# Documentos históricos e obsoletos

Os arquivos deste diretório registram estados anteriores do projeto e foram
preservados apenas para rastreabilidade acadêmica. Eles podem citar SQLite como
arquitetura principal, ausência ou limitações antigas de autenticação, migration
`0007` como head e funcionalidades que já foram alteradas.

Eles **não representam o sistema atual**, não devem orientar instalação ou
operação e não fazem parte do ZIP final de entrega. As fontes canônicas estão
listadas no `README.md` da raiz.

O PDF `Relatorio_Tecnico_Certificados_junho_2026_OBSOLETO.pdf` é a versão de
junho de 2026 mencionada na solicitação de entrega. Seu nome e sua localização
deixam explícito que ele é histórico.
